КАК ВЫЛОЖИТЬ САЙТ
1. Замените SITE-DOMAIN.ru на ваш домен во всех файлах (index.html, editor.html, robots.txt, sitemap.xml).
2. Загрузите всю папку на хостинг. Открывать нужно через http(s), а не двойным щелчком по файлу.
3. Заголовки защиты: _headers (Netlify / Cloudflare Pages), .htaccess (Apache), nginx-security.conf.example (nginx).
   Строка Strict-Transport-Security работает только при включённом HTTPS.
4. Контакты — в js/contacts.js (блок CONTACTS). Цены «средний проект» — в блоке «Что мы делаем» в index.html.
